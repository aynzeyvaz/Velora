## 🚀 About the Velora
Velora is a full-stack travel platform built around a RESTful API. It allows users to browse tours, search destinations, view detailed tour information, and submit booking requests.

The platform also provides hotel and flight information associated with each tour.

---

## 📁 Architecture

Velora is developed with a separated frontend and backend architecture.

---
## Features

- Browse available tours
- Search tours by origin, destination and date
- View detailed tour information
- Hotel information
- Flight information
- Submit booking requests
- RESTful API
